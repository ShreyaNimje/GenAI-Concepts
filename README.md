## 🛠️ Global Prerequisites & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/ShreyaNimje/GenAI-Concepts.git
cd GenAI-Concepts
```

### 2. Set Up a Virtual Environment (Recommended)
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

### 3. Install Core Dependencies
```bash
pip install nltk spacy pandas streamlit
python -m spacy download en_core_web_sm
```

## 📚 Key Concepts Documented

* **Linguistic Foundations:** Tokenization, stop-word filtering, Porter Stemmer vs. WordNet Lemmatization.
* **Syntactic Analysis:** Penn Treebank POS tagging, syntactic dependency hierarchies, and sentence boundary disambiguation.
* **Information Extraction:** Named Entity Recognition (NER), entity linking, and structured knowledge extraction.
* **Modern LLM Architectures:** Embeddings, vector spaces, retrieval-augmented generation (RAG), and fine-tuning pipelines.
