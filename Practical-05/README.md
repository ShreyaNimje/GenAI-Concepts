# Practical 05 – Attention Mechanism

## Aim
To understand and implement a simple Attention Mechanism using Python and NumPy.

## Description
This practical demonstrates how attention scores are calculated between encoder outputs and a decoder hidden state.

The implementation shows:
- Encoder outputs
- Decoder hidden state
- Attention scores
- Context vector
- Basic working of the attention mechanism

## Technologies Used
- Python
- NumPy
- Google Colab / Jupyter Notebook

## Files
- `P5.ipynb` – Implementation of the Attention Mechanism.

## Output
The notebook displays the encoder outputs, decoder hidden state, attention scores, and the calculated context vector.

## How to Run
1. Open `P5.ipynb` in Google Colab or Jupyter Notebook.
2. Run the cells sequentially.
3. Observe the attention scores and context vector.
